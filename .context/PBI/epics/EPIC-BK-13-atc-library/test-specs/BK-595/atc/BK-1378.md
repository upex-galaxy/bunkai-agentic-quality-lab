> Ticket: BK-1378 (BK-595 TC11, P0, AC-03 / 3.1, ROI 10.00)

## 1. Test Case Summary

| Name | Objective | Precondition | Acceptance Criteria |
|------|-----------|--------------|---------------------|
| `expectAtcNotFound` | Reading a well-formed UUID that resolves to no ATC answers 404 `not_found` with `details.reason = 'not_found'` and only the error envelope | Credential holding `atc:read`; no fixture data — the id must not exist | AC-03 / 3.1: 404, `error.code = 'not_found'`, `details.reason = 'not_found'`, top-level keys exactly `['error']`, no ATC metadata in the body |

## 2. ATC Contract

```typescript
/**
 * ATC: Reading a non-existent (or inaccessible) ATC UUID returns a uniform
 * 404 `not_found` with `details.reason = 'not_found'`.
 *
 * Fixed assertions:
 *  - status 404
 *  - top-level body keys are exactly ['error']
 *  - body.error.code is 'not_found'
 *  - body.error.details matches { reason: 'not_found' }
 *
 * The uniform envelope is the point: absent, archived and inaccessible must be
 * indistinguishable, so a stranger cannot enumerate ids.
 */
@atc('BK-1378')
async expectAtcNotFound(nonExistentAtcId: string): Promise<[APIResponse, ErrorEnvelope]>
```

## 3A. API Details

|--------|-------|

| Types | `ErrorEnvelope` (`@schemas/auth.types`), `APIResponse` (`@playwright/test`) |

| Message | `ATC not found.` |
| Source of truth | `app/api/v1/atcs/[id]/route.ts` (GET), `lib/atcs/errors.ts` `mapAtcRpcError` (backend repo, read-only) |

## 4. Assertions Split

### Fixed (inside ATC)

- `expect(response.status()).toBe(404)`
- `expect(Object.keys(body)).toEqual(['error'])`
- `expect(body.error.code).toBe('not_found')`
- `expect(body.error.details).toMatchObject({ reason: 'not_found' })`

### Test-level (in test file)

- The specific non-existent UUID (`11111111-1111-4111-8111-111111111111`): a version-4-shaped UUID that no fixture owns.

## 5. Code Template

```typescript
@atc('BK-1378')
async expectAtcNotFound(nonExistentAtcId: string): Promise<[APIResponse, ErrorEnvelope]> {
  const [response, body] = await this.apiGET<ErrorEnvelope>(`/v1/atcs/${nonExistentAtcId}`);

  expect(response.status()).toBe(404);
  expect(Object.keys(body)).toEqual(['error']);
  expect(body.error.code).toBe('not_found');
  expect(body.error.details).toMatchObject({ reason: 'not_found' });

  return [response, body];
}
```
