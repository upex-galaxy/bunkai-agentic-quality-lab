# ATC Spec: BK-1368 - A single ATC read is lean by default and never cached

> Ticket: BK-1368 (BK-595 TC01, P0, AC-01 / 1.1 + AC-01 / E3, ROI 10.00)
> Component: AtcsApi (`tests/components/api/AtcsApi.ts`, new in this Work Package)
> Type: API - Positive (read contract)
> Parent Story: BK-595 (`TMS-ATC API | Read a single ATC by id`)

## 1. Test Case Summary

| Name | Objective | Precondition | Acceptance Criteria |
|------|-----------|--------------|---------------------|
| `expectLeanAtcRead` | Reading an accessible ATC without `expand` returns 200 with the header fields only, omits every child collection, and marks the response uncacheable | An ATC exists in the caller's workspace and the credential set on the component holds `atc:read` (the `{ api }` fixture preloads the default login PAT) | AC-01 / 1.1: 200, body `{ atc }`, `atc.id` equals the requested id, `title` is a string, `version` is an integer, and `steps` / `assertions` / `acceptance_criteria` / `used_in` / `acceptance_criterion_ids` are all absent. AC-01 / E3: `Cache-Control` contains `private` and `no-store` |

Scope note: the Jira TC lists the full header key set (`slug`, `layer`, `module_id`, `user_story_id`, `project_id`, `created_at`, `updated_at`). Asserting presence of the mutable ones would fight the product (a layer enum grows, `module_id` is nullable). The ATC asserts the stable invariants plus the absence of every expansion key, which is what a regression would actually break.

## 2. ATC Contract

```typescript
/**
 * ATC: Lean read of an ATC by ID returns 200 with header fields, omits all
 * expansion collections, and carries `Cache-Control: private, no-store`.
 *
 * Fixed assertions:
 *  - status 200
 *  - Cache-Control matches /private/ and /no-store/
 *  - top-level body keys are exactly ['atc']
 *  - body.atc.id equals the requested id
 *  - body.atc.title is a string; body.atc.version is an integer
 *  - none of steps, assertions, acceptance_criteria, used_in,
 *    acceptance_criterion_ids is a key of body.atc
 */
@atc('BK-1368')
async expectLeanAtcRead(atcId: string): Promise<[APIResponse, AtcGetResponse]>
```

One positional parameter (the framework limit is two); the credential is not a parameter because it is whatever the fixture set on the component. Returns the standard GET 2-tuple. No helper, no second ATC call.

## 3A. API Details

| Aspect | Value |
|--------|-------|
| Endpoint | `GET /api/v1/atcs/{id}` |
| Types | `AtcGetResponse`, `AtcResource` (`@schemas/atc.types`), `APIResponse` (`@playwright/test`) |
| Auth | `withApiHandler(..., { auth: 'required', requires: ['atc:read'] })` — Bearer `atc:read` or cookie session |
| Handler order | The wrapper resolves the credential and capability first; only then the handler validates the id, parses `expand`, and calls the membership-gated `bunkai_get_atc` RPC |
| Cache header | `PRIVATE_HEADERS = { 'Cache-Control': 'private, no-store' }`, applied on the 200 path only |
| Lean shape | The handler destructures `steps`, `assertions` and `acceptance_criterion_ids` out of the RPC row and spreads the remainder, so those three keys cannot appear unless an expansion is requested |
| Source of truth | `app/api/v1/atcs/[id]/route.ts` (GET), `lib/supabase/rpc.ts` `getAtc` (backend repo, read-only) |

## 4. Assertions Split

### Fixed (inside ATC)

- `expect(response.status()).toBe(200)`
- `expect(cacheControl).toMatch(/private/)` and `/no-store/`
- `expect(Object.keys(body)).toEqual(['atc'])`
- `expect(body.atc.id).toBe(atcId)`
- `expect(typeof body.atc.title).toBe('string')` and `Number.isInteger(body.atc.version)`
- one loop over `FORBIDDEN_LEAN_KEYS` asserting `key in body.atc === false`

### Test-level (in test file)

- The seed ATC id the row reads (`FIXTURE_ATC_ID`). No business assertion is duplicated in the test file.

## 5. Code Template

```typescript
@atc('BK-1368')
async expectLeanAtcRead(atcId: string): Promise<[APIResponse, AtcGetResponse]> {
  const [response, body] = await this.apiGET<AtcGetResponse>(`/v1/atcs/${atcId}`);

  expect(response.status()).toBe(200);

  const cacheControl = response.headers()['cache-control'] ?? '';
  expect(cacheControl).toMatch(/private/);
  expect(cacheControl).toMatch(/no-store/);

  expect(Object.keys(body)).toEqual(['atc']);
  expect(body.atc.id).toBe(atcId);
  expect(typeof body.atc.title).toBe('string');
  expect(Number.isInteger(body.atc.version)).toBe(true);

  for (const forbiddenKey of FORBIDDEN_LEAN_KEYS) {
    expect(forbiddenKey in body.atc, `lean read must not include '${forbiddenKey}'`).toBe(false);
  }

  return [response, body];
}
```
