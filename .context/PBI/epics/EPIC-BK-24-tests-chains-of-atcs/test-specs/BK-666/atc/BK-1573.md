## 2. ATC Contract

```typescript
/**
 * ATC: A tag that matches no Test in this Project shows the copy
 * "No Test carries this tag" with a Clear action. The state is distinct from
 * "No Tests yet", and nothing on screen reads as an error.
 *
 * Fixed assertions:
 *  - the no-match copy is visible
 *  - a Clear action is visible
 *  - the table is absent and no row is shown
 *  - the "No Tests yet" copy is absent
 *  - no role=alert inside the list
 *
 * @param tag - a tag no Test in the Project carries
 */
@atc('BK-1573')
async showsNoMatchStateWithClear(tag: string): Promise<void>
```

## 3A. API Details: none

## 3B. UI Details

| Element | Locator |
|---------|---------|
| Tag input | `[data-testid="test-tag-filter"]` |
| No-match copy | text `No Test carries this tag` (testid **open**, automation-plan Q6) |
| Clear action | role button, name `/clear/i` (testid **open**, Q6) |
| Table | `[data-testid="tests-list-table"]` absent |
| Never-empty copy | text `No Tests yet` absent |

The no-match copy is matched by text on purpose: the testid for this state is not confirmed, and asserting a guessed testid would pass for the wrong reason.

## 4. Assertions Split

### Fixed (inside ATC)
- The copy, the Clear action, the absence of the table, the absence of the never-empty copy, no alert.

### Test-level (in test file)
- The Project holds one `smoke` Test (so it is not empty). The searched tag is `nightly`.

## 5. Code Template

```typescript
@atc('BK-1573')
async showsNoMatchStateWithClear(tag: string): Promise<void> {
  await this.page.locator('[data-testid="test-tag-filter"]').fill(tag);
  const list = this.page.locator('[data-testid="tests-list"]');
  await expect(list.getByText('No Test carries this tag')).toBeVisible();
  await expect(list.getByRole('button', { name: /clear/i })).toBeVisible();
  await expect(this.page.locator('[data-testid="tests-list-table"]')).toHaveCount(0);
  await expect(list.getByText('No Tests yet')).toHaveCount(0);
  await expect(list.getByRole('alert')).toHaveCount(0);
}
```
