 * ATC: The Tests list of a Project shows that Project's own Tests and never

 *  - no foreign title appears anywhere in the list

 * @param scope - the Project slug, its own Test titles, and another Project's Test titles

@atc('BK-1562')
async listsOnlyCurrentProjectTests(scope: ProjectTestsScope): Promise<void>

## 4. Assertions Split

### Fixed (inside ATC)
- Each own title visible in the table.
- Each foreign title absent from the list root (`not.toContainText`).

### Test-level (in test file)
- The test calls the ATC once per Project (P1 then P2, roles swapped). That is the Gherkin's "A's list shows only A's, B's list shows only B's".

## 5. Code Template

```typescript
@atc('BK-1562')
async listsOnlyCurrentProjectTests(scope: ProjectTestsScope): Promise<void> {
  const list = this.page.locator('[data-testid="tests-list"]');
  await expect(list).toBeVisible();
  for (const title of scope.ownTitles) {
    await expect(list).toContainText(title);
  }
  for (const title of scope.foreignTitles) {
    await expect(list).not.toContainText(title);
  }
}
```

The test calls `open(slug)` before this ATC, so the URL is correct. The ATC does not navigate.
