## 2. ATC Contract

```typescript
/**
 * ATC: The Name column sorts the Tests list by name ascending on the first
 * click, and reverses the order on the second click. The sort lives in the URL.
 *
 * Fixed assertions:
 *  - first click: URL carries sort=name&dir=asc, rows are in ascending order
 *  - second click: URL carries dir=desc, rows are the reverse order
 *
 * @param expectedAscending - the titles in ascending order (Name sort)
 */
@atc('BK-1574')
async sortsByNameAscendingThenReverses(expectedAscending: string[]): Promise<void>
```

## 4. Assertions Split

### Fixed (inside ATC)
- URL state after each click; the exact row order after each click.

### Test-level (in test file)
- Three Tests with titles that start with `Alpha`, `Bravo`, `Charlie` (plus a unique suffix). The leading word fixes the expected ascending order without depending on the comparator's tie-breaks. The live product compares naturally and case-insensitively (TC-15 evidence), which agrees with this order.

## 5. Code Template

```typescript
@atc('BK-1574')
async sortsByNameAscendingThenReverses(expectedAscending: string[]): Promise<void> {
  const header = this.page.locator('[data-testid="tests-list-sort-name"]');
  await header.click();
  await expect(this.page).toHaveURL(/sort=name/);
  await expect(this.page).toHaveURL(/dir=asc/);
  expect(await this.renderedTitles()).toEqual(expectedAscending);

  await header.click();
  await expect(this.page).toHaveURL(/dir=desc/);
  expect(await this.renderedTitles()).toEqual([...expectedAscending].reverse());
}
```

`renderedTitles()` is a private helper on the component: it reads the row testids in DOM order and maps them to the displayed title. It is not decorated.
