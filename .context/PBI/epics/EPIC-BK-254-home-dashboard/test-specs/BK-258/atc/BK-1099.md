## 4. Assertions Split

- Fixed (ATC): skeleton gone, total, four chips.
- Test level, before the action: `getOpenBugs(A)` must equal A's seed exactly and `getOpenBugs(B)` must equal B's seed exactly. Fresh workspaces start empty, so the counts are absolute, not deltas, and the oracle proves B's bugs exist and are counted for B (the test cannot pass vacuously).
- Test level, per row: the ATC with the active workspace's counts, then `getOpenBugs(active)` must still equal them (API agrees with the card).

**Deviation from the TC wording (decided, recorded).** The TC switches workspace through the UI switcher. The automation switches through `selectWorkspace()` (POST `/v1/me/active-workspace` in the page's own cookie jar), the established pattern of BK-1096 and the BK-266 tests. The switcher is navigation chrome, not the behaviour under test; the outcome (which workspace the card counts) is identical, and the API route avoids a locator dependency on a component this TC does not own. The TC's own workspace ids (`{workspace_id}`, the "BK-258 QA Fixture" workspace) are replaced by two workspaces generated per run: decision taken with the user on 2026-10-25.

## 5. Code Template

ATC implementation (added to `HomePage`, reuses `waitForCardSettled`, `SEVERITIES`, `SEVERITY_LABELS`):

```typescript
@atc('BK-1099')
async showsOnlyActiveWorkspaceOpenBugs(expected: OpenBugsCounts): Promise<void> {
  await this.waitForCardSettled();
  const card = this.page.getByRole('region', { name: 'Open bugs' });

  await expect(card.getByTestId('home-open-bugs-count')).toHaveText(String(expected.total));
  for (const severity of SEVERITIES) {
    const chip = card.getByTestId(`home-open-bugs-severity-${severity}`);
    await expect(chip).toBeVisible();
    await expect(chip).toHaveText(new RegExp(`^${severity}\\s*${SEVERITY_LABELS[severity]}\\s*${expected[severity]}$`));
  }
}
```
